| **Project Mission** |
| :---: |
| This project is a technology manifesto, brought to life by a high school student with personal funds, aiming to fundamentally change how visually impaired individuals perceive the world. The mission is to create an assistive device that doesn't just warn about an obstacle, but **describes and interprets the environment**—a cognitive companion that can say "the sign ahead reads 'exit'" instead of just beeping. This vision was validated by winning an award at an international robotics competition. |

This repository serves as a comprehensive technical archive for the EGG project, detailing its entire lifecycle from concept to an award-winning prototype.

**Disclaimer:** The source code and design files in this repository are provided for demonstration purposes only. All rights are reserved, and this project is **not open-source**.
